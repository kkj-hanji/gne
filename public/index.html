    ANDROID APP

    Kotlin + Cloudflare + GitHub

    The Kotlin Android shell connects to the existing GNDEC Compass service.

    • Kotlin Android app: opens Compass in an Android WebView and keeps its profile and preferences in app-local web storage.
    • Cloudflare Worker: serves the live Compass website and online APIs.
    • Offline use: the existing PWA cache can reopen previously loaded app files after a successful online visit.
    • GitHub Actions: builds a debug APK artifact when Android project files change.

    The first launch needs internet access. Android-only features such as Room synchronization, alarms and push notifications are not part of this initial APK.
